# Migration: v0.12 → v0.15

## Headline

- Named **recipes** introduced — bundles of patterns with shared
  intent.
- MCP server (`vstack-mcp`) added — 35 tools for Claude
  Desktop / Cursor / Cline integration.
- 5 new patterns: Group Decision Models, Stone-Heen Triggers,
  Plus-Delta, SMART Goals, Span of Control.

## What changed

### Added: named recipes

`diagnose()` now accepts a `recipe=` argument that selects a
curated bundle:

```python
from vstack import diagnose

# Recipe-driven (new):
report = diagnose(trace=trace, llm_client=llm, recipe="stuck_in_loop")

# Pattern-driven (still works):
report = diagnose(trace=trace, llm_client=llm, patterns=["lewin", "aar"])
```

The catalog ships 8 initial recipes in v0.15 (expanded to 33 in
v0.19.0). Browse via:

```bash
vstack-recipes list
vstack-recipes show stuck_in_loop
```

Or in Python:

```python
from vstack.diagnose import RECIPES, list_recipes_by_cluster

for name, info in RECIPES.items():
    print(name, info.patterns)
```

### Added: MCP server

`vstack-mcp` is a Model Context Protocol server that exposes every
pattern + diagnose + recipe as tools for compatible clients:

```bash
vstack-mcp --help
vstack-mcp stdio    # for Claude Desktop / Cursor / Cline
vstack-mcp http     # for SSE-capable clients
```

Configure in Claude Desktop / Cursor / Cline by adding to the MCP
config:

```json
{
  "mcpServers": {
    "vstack": {
      "command": "vstack-mcp",
      "args": ["stdio"]
    }
  }
}
```

### Added: 5 new patterns

- **#25 Group Decision Models** (`vstack.group_decision`).
- **#22 Stone-Heen Triggers** (`vstack.feedback_triggers`).
- **#23 Plus-Delta** (`vstack.plus_delta`).
- **#24 SMART Goals** (`vstack.smart_goal`).
- **#34 Span of Control** (`vstack.span_of_control`).

All five follow the same surface (analyzer + async + schema +
prompts + composition).

## Required code changes

None. All v0.12 surfaces are unchanged.

If you want to *migrate* existing pattern-driven `diagnose()` calls
to recipe-driven:

```python
# Before (v0.12):
report = diagnose(
    trace=trace,
    llm_client=llm,
    patterns=["lewin", "aar", "bias_stack", "yerkes_dodson"],
)

# After (v0.15) — matches the canonical stuck-in-loop recipe:
report = diagnose(trace=trace, llm_client=llm, recipe="stuck_in_loop")
```

The migration is optional.
