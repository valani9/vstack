# Migration: v0.20 → v0.22

## Headline

- 34 per-pattern WALKTHROUGH.md docs shipped (v0.21.0).
- 24 new cookbook scripts shipped (v0.22.0).
- 34 per-pattern starter demos shipped (v0.22.0).
- 25 new trace fixtures shipped (v0.22.0).
- Pure docs + examples release. No API changes.

## What changed

### Added: 34 per-pattern WALKTHROUGH.md docs

Each pattern under `module-*-*/NN-name/` now has a WALKTHROUGH.md
companion document covering 5 real-world scenarios with the call
shape + expected output + intervention bundle:

```bash
ls module-*-*/*/WALKTHROUGH.md
# 34 files
```

These are pure documentation. No code or schema changes.

### Added: 24 new cookbook scripts

Every named recipe in the catalog now has a runnable cookbook
script. Browse via:

```bash
ls examples/cookbook/
# 38 .py files (was 14 before v0.22.0)
```

Each script runs without an API key (StubClient) and prints an
intervention bundle.

### Added: 34 per-pattern starter demos

Smallest runnable demo per pattern, under `examples/patterns/`:

```bash
python examples/patterns/01_lewin.py
```

These complement the deeper per-pattern demos under
`module-*-*/NN-name/demo/` — use them when you want the minimum
call surface, not the full walkthrough.

### Added: 25 new trace fixtures

The shared trace library at `examples/_shared/traces.py` expanded
from 12 → 36 fixtures. New fixtures cover every cookbook recipe's
scenario:

```python
from examples._shared.traces import (
    overconfidence_spiral_trace,
    premature_completion_trace,
    healthy_individual_trace,
    healthy_team_messages,
    # ... 21 more
)
```

### Added: 6 framework integration playbooks

Per-framework playbooks under `docs/integrations/`:

- `langchain.md`
- `langgraph.md`
- `crewai.md`
- `autogen.md`
- `pydantic-ai.md`
- `llama-index.md`

Each playbook covers the adapter, the 8 patterns most useful for
that framework's failure modes, and a production wiring snippet.

### Added: 5 per-cluster combined recipe demos

Under `examples/clusters/`:

```bash
python examples/clusters/01_reasoning_combined.py
python examples/clusters/02_coordination_combined.py
python examples/clusters/03_trust_combined.py
python examples/clusters/04_workload_combined.py
python examples/clusters/05_culture_combined.py
```

Each runs the recipes for a cluster against representative traces
and prints a comparative summary.
