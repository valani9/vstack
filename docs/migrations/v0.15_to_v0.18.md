# Migration: v0.15 → v0.18

## Headline

- FastAPI server (`vstack-api`) added — 35 HTTP endpoints.
- Auth + rate limiting + observability added.
- 8 more patterns: HEXACO, Devil's Advocate, Schein, Robbins-Judge,
  Org Structure, plus refinements to Group Pathology and
  Bias Stack.
- `vstack-mcp` now ships with prompt templates per pattern.

## What changed

### Added: FastAPI server

`vstack-api` is a production FastAPI server that exposes every
pattern + diagnose + recipe as REST endpoints:

```bash
vstack-api serve --port 7777
curl http://localhost:7777/v1/lewin -d '{"trace": {...}}'
curl http://localhost:7777/v1/diagnose -d '{"trace": {...}, "recipe": "stuck_in_loop"}'
```

Auth modes:
- `VSTACK_API_AUTH=none` — no auth (dev).
- `VSTACK_API_AUTH=bearer` — bearer token via `VSTACK_API_TOKEN`.
- `VSTACK_API_AUTH=hmac` — HMAC signed requests.

Rate limiting via token bucket; configure via env vars.

Observability:
- Structured JSON logs with `run_id` correlation.
- Prometheus metrics at `/metrics`.
- OpenAPI schema at `/openapi.json`.

### Added: 8 new patterns

Full list in `docs/PATTERNS_OVERVIEW.md`. New as of v0.18:
- **#07 HEXACO Personality** (`vstack.hexaco`).
- **#28 Devil's Advocate Separator** (`vstack.devils_advocate`).
- **#31 Schein Iceberg** (`vstack.schein_culture`).
- **#32 Robbins-Judge 7-Culture** (`vstack.robbins_culture`).
- **#33 Org Structure Matrix** (`vstack.org_structure`).
- Refinements to #26 Group Pathology, #27 Bias Stack.

### Added: MCP prompt templates

Each pattern's MCP tool now ships with a prompt template suitable
for end-user invocation in Claude Desktop / Cursor / Cline:

```bash
vstack-mcp prompts list
vstack-mcp prompts show lewin
```

## Required code changes

### Mypy `strict` users

The FastAPI server module (`_api/lib/_app.py`) tightened type
annotations. If you're using `--strict` mypy and importing from
`vstack._api`, you may see new `arg-type` errors for trace
serialization. Fix by adding a narrowed local before passing to
`anyio.to_thread`:

```python
# Before:
result = await anyio.to_thread.run_sync(detector.run, trace, shape=payload.shape)

# After:
shape_arg: TraceShape | None = (
    payload.shape if payload.shape is not None else None
)  # type: ignore[assignment]
result = await anyio.to_thread.run_sync(detector.run, trace, shape=shape_arg)
```

This only affects code that *imports from* `_api`; if you're
consuming the API via HTTP, no change.
