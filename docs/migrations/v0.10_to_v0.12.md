# Migration: v0.10 → v0.12

## Headline

- `vstack.diagnose()` cross-pattern runner is now the canonical
  entry point.
- Per-pattern analyzers are still supported and unchanged.
- Trace shape (`AgentTrace`) added to the canonical surface.

## What changed

### Added: `vstack.diagnose()`

A new top-level function that runs a curated bundle of patterns
against a single trace and returns a unified `DiagnoseReport`.

```python
from vstack import diagnose
from vstack.aar import AgentTrace, TraceStep
from vstack.aar.clients import AnthropicClient

trace = AgentTrace(
    goal="...",
    steps=[TraceStep(type="thought", content="...")],
    outcome="...",
    success=False,
)

report = diagnose(trace=trace, llm_client=AnthropicClient())
print(report.to_markdown())
```

The runner infers `shape` (individual / team / org) from trace
attributes and runs the appropriate default bundle. Override with
`recipe=` or `patterns=` arguments.

### Added: `vstack.PATTERNS` registry

Maps pattern slugs to their analyzer classes:

```python
from vstack import PATTERNS

for slug, info in PATTERNS.items():
    print(slug, info.analyzer)
```

### Added: shape-typed traces

The `AgentTrace` schema accepts a `shape` field. v0.10 inferred
shape implicitly; v0.12 makes it explicit:

```python
from vstack.aar import AgentTrace

trace = AgentTrace(
    shape="team",         # NEW in v0.12 (auto-inferred if omitted)
    goal="...",
    steps=[...],
    success=True,
)
```

## What didn't change

- Per-pattern analyzer classes (`LewinAttributionDetector`,
  `GolemanEIAuditDetector`, etc.) are unchanged.
- Per-pattern import paths (`vstack.lewin`, `vstack.goleman_ei`,
  etc.) are unchanged.
- Per-pattern wire formats are unchanged.

## Required code changes

None. The `diagnose()` API is purely additive.

If you want to *migrate* existing per-pattern code to `diagnose()`,
the transformation is:

```python
# Before (v0.10):
from vstack.lewin import LewinAttributionDetector
from vstack.aar import AAR
from vstack.aar_generator import AARAnalyzer

lewin_result = LewinAttributionDetector(llm).run(trace)
aar_result = AARAnalyzer(llm).run(trace)

# After (v0.12):
from vstack import diagnose
report = diagnose(trace=trace, llm_client=llm, patterns=["lewin", "aar"])
lewin_finding = next(f for f in report.findings if f.pattern == "lewin")
aar_finding = next(f for f in report.findings if f.pattern == "aar")
```

The migration is optional — direct per-pattern usage is still the
recommended pattern for production where you only need one
diagnostic.

## Deprecated

Nothing. v0.10 surfaces are unchanged.

## Removed

Nothing.
